# Isaac Pad

A custom 12-key macropad designed for gaming indie games that require 12 keys or less to be properly enjoyed.

## Specifications

- Microcontroller: Seeed XIAO RP2040
- 12 MX-style mechanical switches
- Matrix: 4 rows x 3 columns
- Firmware: QMK
- 12 diodes

## Features

- Custom-designed PCB
- Custom 3D-printed enclosure
- 12 programmable mechanical keys
- QMK Firmware
- Compact and real sleek design

## Design files
This repository includes:
- Kicad PCB files(inside of hardware/pcb)
- Gerber manufacturing files(inside of hardware/pcb)
- 3d models(inside of hardware/case)
- STEP assembly model(inside of hardware/case)
- Bill of materials (inside documentation folder)
